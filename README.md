# PSA testing for prostate cancer: benefits and risks

This repository contains a one-page patient guide for England. It explains what a PSA blood test can and cannot tell you, the possible benefits and harms, and the difference between testing an individual and screening a population.

Open `index.html` in a browser with the `assets` directory alongside it. The page uses the layout from the `BeaconV/rosuvastatin` template and does not require a build step.

Guidance checked **20 November 2026** against the [UK National Screening Committee recommendation](https://view-health-screening-recommendations.service.gov.uk/prostate-cancer/), [England’s implementation update](https://www.gov.uk/government/publications/mens-health-strategy-one-year-on-report/mens-health-strategy-one-year-on-report) and the [NHS PSA test guide](https://www.nhs.uk/tests-and-treatments/psa-test/).
